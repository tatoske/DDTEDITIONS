Proyecto de desarrollo para la plataforma **D&D T Editions**.

## Estructura Inicial del Proyecto

```text
D&D T Editions/
├── .agents/
│   └── agents/               # Definiciones de agentes del Squad
│       ├── orchestrator.md
│       ├── product-owner.md
│       ├── scrum-master.md
│       ├── db-specialist.md
│       ├── backend-specialist.md
│       ├── frontend-specialist.md
│       ├── qa-specialist.md
│       └── data-scientist.md
```

## Squad Activo

El proyecto cuenta con un equipo multi-agente configurado y listo para operar:
- **Orchestrator (Tech Lead)**
- **Product Owner**
- **Scrum Master**
- **DB Specialist**
- **Backend Specialist**
- **Frontend Specialist**
- **QA Specialist**
- **Data Scientist / AI Specialist**
